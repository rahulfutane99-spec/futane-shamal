SHAMAL BIRTHDAY WEBSITE — LATEST UPDATE

FILES
- index.html: Home page
- memories.html: All 9 photographs with individual heartfelt notes
- quiz.html: Love quiz
- letter.html: Birthday letter
- surprise.html: Final birthday surprise
- style.css / script.js
- assets/: all 9 original photographs and original instrumental birthday melody

HOW TO PREVIEW
1. Extract this ZIP.
2. Open index.html in a browser.
3. Click through Home → Memories → Love Quiz → Letter → Surprise.
4. Tap “Play birthday music” to start the instrumental (browsers require a tap before audio can play).

HOW TO PUBLISH ON GITHUB PAGES
1. Upload the contents of this ZIP to the root of your GitHub repository (not the ZIP itself).
2. Keep the assets folder alongside the HTML files.
3. In Settings → Pages, select Deploy from a branch, choose main and /(root), then Save.
4. Your existing GitHub Pages address can remain the same.

PHOTO NOTES
All nine photos from STRF.zip are included in the Memories page, in the same order as the uploaded archive. Each has its own personal caption. You can edit the wording in memories.html.

MUSIC
An original gentle instrumental birthday melody is included as assets/birthday-melody.wav. It is not an existing commercial song.
